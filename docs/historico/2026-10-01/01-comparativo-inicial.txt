## 7. CARACTERÍSTICAS ESPECÍFICAS DE CODEMATCH

### Búsqueda por Dimensiones (QMS-0.1)
- **Desarrollado/Plegado:** COMBINABLES (campos independientes)
  - `developedLength`, `developedWidth` (diseño extendido)
  - `foldedLength`, `foldedWidth`, `foldedHeight` (diseño doblado)
  - Búsqueda: `#searchLength` y `#searchWidth`
- **Función dimsMatch:**
  ```javascript
  dimsMatch(a, b, x, y, tol)
  // Compara pares de dimensiones
  // - direct: a~=x AND b~=y
  // - swapped: b~=x AND a~=y
  // Retorna {ok, distance, swapped}
  ```

### Sumatorio de Cotas (QMS-0.1)
- **Estructura:** `foldCotas[foldCalcTarget]` = array de 3 elementos
  ```javascript
  foldCotas.searchLength = ['', '', '']
  foldCotas.searchWidth = ['', '', '']
  ```
- **UI:** Dialog #foldCalcDialog con
  - Botón "Cota 1", "Cota 2", "Cota 3"
  - Inputs numéricos step="0.1"
  - Botón "+ Añadir cota" (expande del 3)
  - Botón "Limpiar cotas"
  - Total mostrado en tiempo real
- **Exactitud:** Array DINÁMICO (`.push(''), .splice(index, 1)`) - NO limitado a 2x4 en código

### Medición por Planos (QMS-0.1)
- **3 vistas:** Planta (0), Alzado/Lateral (1), Isométrica/Oblicua (2)
- **Estructura queryViews[slot]:**
  ```javascript
  {
    file: File,
    thumb: DataURL,
    feature: descriptor,
    arucoDetected: bool,
    planeCalibrated: bool,
    planeCalibration: {markerId, homography, markerSizeMm, sourceWidth, sourceHeight},
    estimated: {length, width},
    measurementSource: 'manual' | 'confirmed' | 'automatic',
    manualDimensions: {...}
  }
  ```
- **Medidas finales combinadas:**
  - Largo: Planta.length
  - Ancho: Planta.width
  - Alto: Alzado.width (como altura)

### Importación/Exportación Excel (QMS-0.1)
- **Entrada:** .xlsx o .csv
- **Mapeo dinámico:** Usuario selecciona columnas (código, denominación, largo, ancho)
- **Función parseSpreadsheet:**
  - Lee xl/sharedStrings.xml (strings)
  - Lee xl/workbook.xml
  - Parse xl/worksheets/sheet1.xml
  - Crea matriz de celdas
- **Salida:** Importa a IndexedDB records con source='excel', dataSource='Excel'
- **Exportación:** genera XLSX con estructura completa usando JSZip
